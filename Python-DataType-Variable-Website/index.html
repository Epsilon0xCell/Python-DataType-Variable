Python-DataType-Variable

Basic Python datatype and variable script

Objective. By the end of this page you will have read the whole program. It takes about ten seconds, and that is the right amount of time for it.

The whole program: variable.py

keys = "fun"
print(keys)

Output, checked by running it: fun · exit code 0

What this is

I kept this repo at two lines. The first line binds the string "fun" to the name keys. The second line prints what that name points at. That is the smallest useful Python program I know: bind a value to a name, then use the name.

The lesson in the name of the repo is the data type point. keys holds a str here, and the same name could hold an int or a list later, because Python variables are labels on values, not typed boxes. The header comment in variable.py says exactly that, and the two lines below it prove it by running.

Line by line

LineWhat happens
keys = "fun"The string value fun is created and the label keys is attached to it. Nothing is printed yet.
print(keys)print() looks up the label and writes the value it points at, then a newline. It prints fun, not the word keys.

Why it was not inflated

In Deep Wave 1 I had the chance to grow this repo and I left it alone on purpose. A two line beginner snippet does not get functions, classes, or a command line interface. Anything more would misrepresent what the repo is. The only change in that pass was the header comment stating the lesson.

So this site is small for the same reason. If you came here looking for a larger project, this is not it, and I would rather say that on the lesson page than pad the lesson.

Run it

From the repo root, with Python 3:

python3 variable.py
