Python-DataType-Variable

A single day sheet from the copying room. The program in this repo is very small: variable.py holds one assignment and one print call, and running it shows what the name currently points at. Nothing else is claimed for it, because nothing else is in the file.

Entry one: the binding Entry two: the result Entry three: trying it The repository

Entry one

The binding itself

Marginal gloss: a variable is a label stuck on a value, not a box built for one kind of thing.

Here is the whole working part of the file, set as an inked block on the sheet, exactly as variable.py has it:

keys = "fun"
print(keys)

The name keys is tied to the string "fun". A short comment at the top of the file makes the one idea the file teaches: the same name could later be tied to a whole number or a list, and the print call would still show whatever it points at on that run. Checked against a run, type(keys) reports a string, len("fun") is 3, and the first letter sits at position 0.

Entry two

The result

Run the file and this is what comes back, set large in lapis:

fun

That is the complete output of the program. One word and a newline, exit code 0, and nothing follows it. The honesty about size is part of the lesson: a first program does not need to be big to show how a name, a value, and a print call fit together.

Entry three

Trying it

Python on its own is enough. There are no added libraries to install and nothing to set up. From a terminal, in the folder that holds the file:

python3 variable.py

Then change the string between the quotes, run it again, and watch the printed word change while the rest of the file stays untouched. That edit and rerun loop is the only interaction this repo offers, and this page says so rather than dress it up.
